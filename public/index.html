roomindex

Search rooms by name, paste a save blob key or hash to find out which room it belongs to, or enter an account id to list every room it created, owns, or saved in.

Blob keys look like 13pcfb752scyh8j7eozjpqbsh.room. Room metadata blobs look like room/…​.meta. Hashes are the base64 strings next to them.

Pick a room to see everything stored about it.
